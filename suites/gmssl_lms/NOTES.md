# GmSSL: lms

This suite is one of four images built from the same sources. The sources
are in `suites/gmssl/common/` and the notes (origin and license of the code,
what was changed, measurements, what does not work) are in
`suites/gmssl/NOTES.md`. The upstream code is in `third_party/gmssl/`
(Apache-2.0, see `SOURCE.md` there).
